# 30. Accesos para cuando vuelvas al ordenador

28 de octubre de 2026. El usuario pidió separar cuentas, APIs y voz del trabajo
local. Después de entregar el visor autorizó continuar con la checklist y dejar
pendiente su intervención. Esta lista reúne esas dependencias externas; la
continuación local no crea cuentas, acepta licencias, gasta GPU ni reanuda
los ensayos pagados de voz. Esta introducción describe ese hito histórico; el
objetivo integral posterior volvió a incluir cuentas y pruebas reales acotadas.
La comprobación de visión Meta y sus límites están en la entrega 35.

## Reconstrucción espacial

- [ ] Confirmar cuenta Modal, solicitud de créditos del evento, saldo real y presupuesto por trabajo/total.
- [ ] Autenticar el SDK Modal en el equipo donde se desplegará el worker.
- [ ] Obtener acceso a checkpoints Meta y revisar/aceptar sus licencias en la cuenta del usuario.
- [ ] Descargar y comprobar hashes de pesos; completar el lock y comprobar dependencias CUDA.
- [ ] Elegir habitación y tres objetos; grabar una captura real y revisar una máscara del primer objeto.
- [ ] Aprobar el presupuesto concreto antes de habilitar un primer trabajo remoto.
- [ ] Desplegar y comprobar una sola reconstrucción; comparar la geometría con el objeto real.

El visor y el almacenamiento local pueden funcionar sin estos accesos. Una
escena procedural de demostración no acredita reconstrucción de una captura.

## Voz y traducción

- [ ] Volver a la elección del motor con acceso disponible: OpenAI API con saldo o ElevenLabs Realtime Enterprise, según corresponda.
- [ ] Introducir la clave en el formulario local, sin enviarla al chat.
- [ ] Ejecutar una única muestra de dos frases con revisión sintética y traza.
- [ ] Revisar contenido y medir la salida con alcance adecuado antes de afirmar ≤500 ms audibles.

El objetivo integral actual incluye voz y traducción. Las claves ya guardadas se
conservan; el objetivo audible de 500 ms sigue pendiente y necesita un ensayo
acotado que resuelva una duda concreta, sin repetir proveedores por rutina.

## Conexiones personales y sociales

- [ ] Crear/configurar cliente OAuth Google de tipo Desktop app y habilitar
  Calendar, Gmail y Drive en el proyecto Google; completar consentimiento real
  desde `/connections`. La autorización del plugin de Codex no se transfiere.
- [ ] Configurar número y token WhatsApp Business, secreto de firma y token de
  verificación, consentimiento del chat propio y proxy público HTTPS del receptor
  aislado. No publicar el servidor principal de Brivany.
- [ ] Verificar intercambio/renovación y una operación de cuenta autorizada;
  en esta entrega todas las APIs personales/sociales usaron transportes sustituidos.
- [ ] Completar cuentas, permisos/revisión Meta y presupuesto explícito para
  Facebook/Instagram y anuncios. El borrador local no autoriza publicación o gasto.
- [ ] Probar Keychain de macOS y OAuth móvil; el cifrado comprobado es DPAPI Windows.

## Evento y capacidades posteriores

- [ ] Confirmar condiciones, fecha de entrega, entregables y criterios del hackatón en su fuente oficial.
- [ ] Evaluar hardware/SDK de Meta Glasses cuando esté disponible.
- [ ] Aportar la arquitectura de Spaik Iris; permanece pendiente.

La revisión de captura, edición, variantes y exportación pueden seguir sin
estos accesos. La primera reconstrucción real de un objeto con el worker remoto
requiere completar las dependencias anteriores y su presupuesto.

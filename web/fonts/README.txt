BRIVANY EDITORIAL — prototype v0.1

Contains three installable TTF fonts: Light, Regular, Medium.
Supported Latin glyphs include Spanish accents, ñ, ü, ¿, ¡.

Concept: premium sans editorial, open counters, soft organic curves, slight optical width adjustments and editorial rhythm.

The font is an initial functional prototype modified from Lato (OFL); not a final typeface drawn from scratch.

Install: double-click each TTF in Windows/macOS and select Install; in design apps search for “Brivany Editorial”.
